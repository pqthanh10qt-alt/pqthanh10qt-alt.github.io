Core features

The application is designed around explicit user control and repeatable content workflows.

Channel management

Connect and organize authorized social accounts and group channels used by the same content team.

Content calendar

Prepare publishing schedules, review planned posts and keep content timing organized.

Media library

Store and reuse videos, images and approved assets for publishing workflows.

Publishing workflow

Inbox workspace

Bring supported customer interactions into one workspace when the connected platform provides authorized API access.

Customer organization

Keep useful customer context and interaction history inside the application for authorized business workflows.

TikTok integration

TIGO Social Manager is designed to use TikTok's official authorization and Content Posting APIs. Availability of each feature depends on TikTok approval and the scopes granted by the user.

Connect with TikTok

The user selects “Connect TikTok” in TIGO Social Manager and is sent to TikTok's official authorization screen.

Review permissions

TikTok shows the permissions requested by the application. The user can approve or cancel. TIGO Social Manager does not collect the user's TikTok password.

Return to TIGO Social Manager

After successful authorization, the application identifies the connected account using information permitted by the approved scopes.

Choose content and publish

The user explicitly selects media, the connected account and available post settings. Content is sent only after the user confirms the action.

Disconnect at any time

The user can disconnect the account in the application and can also revoke access through TikTok account settings.

Privacy and account safety

Platform access is limited to the permissions required for enabled features.

No password collection

Social platform passwords are never requested by TIGO Social Manager. Authentication is handled by the platform's authorization flow.

Explicit publishing choice

The user controls which content and account are used. The application does not silently publish content without the configured user action or schedule.

Revocable access

Users can disconnect an account and revoke third-party access through the connected platform.

Data minimization

We request only the platform data and scopes needed for the specific feature the user is using.
