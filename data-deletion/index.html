Data Deletion

TIGO Social Manager

Users can remove connected-account access and application data using the methods below.

1. Disconnect a social account

Open TIGO Social Manager, go to Channels & Groups, select the connected account, and choose the disconnect/remove action. You can also revoke TIGO Social Manager from the social platform's own connected-app or authorization settings.

2. Delete local application data

Delete the relevant saved media, drafts, customer records or projects inside TIGO Social Manager. If you no longer use the application, uninstall it and remove its local application data folder from your computer.

3. Request deletion of server-side data

If a feature has stored account or integration data on TigoSoft infrastructure, send a deletion request to pqthanh.10qt@gmail.com. Include the connected platform, the account display name or identifier, and enough information for us to verify the request. Do not send passwords or access tokens.

4. What happens after a verified request

After a valid request is verified, we will delete or anonymize applicable TigoSoft-held data unless retention is required by law, security obligations or a platform's mandatory requirements. Revoking the platform authorization may also invalidate the associated token independently of TigoSoft.

For more information, see the Privacy Policy.
